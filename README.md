# مشروع AI Agent لشركة سياحة

## التشغيل على Windows
1. ثبّت Python من https://www.python.org/downloads/ (علّم على Add python.exe to PATH).
2. فك الضغط عن الفولدر، وانسخ `.env.example` باسم `.env`.
3. دوس دبل كليك على `setup.bat` (بيسألك عن المفتاح ويعمل .env)، وبعدها `run.bat`.
4. أول مرة هتظهرلك كلمة سر الأدمن في الشاشة. احفظها.
5. افتح http://127.0.0.1:8000 — ولوحة الموظفين على /admin

## تشغيل الذكاء الاصطناعي
حط مفتاح واحد بس في `.env`: `GEMINI_API_KEY` (فيه مستوى مجاني) أو `ANTHROPIC_API_KEY` (مدفوع). من غير مفتاح الشات بيشتغل بوضع تجريبي.
تنبيه: في المستوى المجاني لـ Gemini، جوجل ممكن تستخدم المحادثات لتحسين منتجاتها، يعني بيانات العملاء بتروح لها.

## اختبار المنطق
`python test_agents.py` و `python test_gemini.py`

## الملفات
- server.py: السيرفر والـ API والحماية
- agents.py: الوكلاء الثلاثة وأدواتهم
- db.py: قاعدة البيانات (travel.db بتتعمل تلقائي)
- static/: صفحات الموقع ولوحة التحكم

الرحلات في البداية **بيانات تجريبية**؛ عدّلها من لوحة التحكم.
